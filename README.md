CodeByDex - Personal Portfolio Website

Welcome to the official repository for CodeByDex, the personal developer portfolio website of Dexter James P. Alonzo Software Developer based in Tagum City, Davao del Norte.

Key Features

- Responsive Navigation Bar: Includes a mobile-friendly slide/toggle navigation menu.
- Hero Section: Features a dynamic role typing effect and an instant CV download link.
- Interactive About Section: Expandable bio text using JavaScript for a cleaner presentation.
- Projects Showcase Grid: Card layout displaying highlighted software, AI, and web development projects.
- Categorized Skills Dashboard: Progress bars displaying proficiency across Languages, Frontend, Backend, and Tools.
- Functional Contact Form: Integrated with EmailJS to send messages directly from the user without requiring a backend server.
- Social Links: Quick access to external profiles.

Tech Stack and Dependencies

- Frontend: HTML5, Custom CSS3, JavaScript (Vanilla ES6)
- Icons: Font Awesome 6.4.0
- Contact Service: EmailJS Browser SDK v3
